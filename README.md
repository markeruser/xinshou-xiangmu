# xinshou-xiangmu

这是一个用于学习与实验的小项目合集，内容已按项目分类整理。

## 项目

### 四则运算计算器

路径：[`projects/calculator/`](projects/calculator/)

- 提供加、减、乘、除四个函数
- 除数为 0 时会抛出明确错误
- 使用 pytest 覆盖正常运算与异常情况

### 鹈鹕的兜风日（3D版）

路径：[`projects/pelican-bike/`](projects/pelican-bike/)

- 基于 Three.js r186 的 3D 互动网页
- 支持速度、亮度、暂停和相机交互
- Three.js 已放在项目目录内，可离线运行
